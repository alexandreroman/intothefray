# Automated setup scope

"Set up the table" places the villain and main scheme, builds and shuffles
the encounter deck (with each hero's obligation), places starting threat,
sets aside nemesis sets, puts each identity in play (alter-ego face) and
shuffles each player deck. Hands start empty: players draw their own
opening hand. Scenario "Setup:" instructions and the mulligan are also
done by hand.

**Why:** some heroes and cards change the opening draw, so drawing by hand
is simpler and always correct.

**How to apply:** never add an automatic opening draw; the Draw… action
covers it.
