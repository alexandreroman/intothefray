# Memory notes carry no dates

Memory notes carry no dates, in their body or their **Why:** line. Their
content is timeless: it states each decision as a standing fact, with the
reason behind it.

**Why:** user preference: a note reports decisions, not when they were
taken.

**How to apply:** a **Why:** line gives the reason for the decision
("user decision: …"), never "user decision of <date>". Dates belong to
git history and to the local design specs.
